# Plan: Add broadcast_msg to Sine SDK + broadcast_demo.lua

## Context
The module/demo split is complete. The next step is adding `M.broadcast_msg(origin, payload)` to
the SDK — a fire-and-forget write command that sends a `viSendBroadcastMessage` (type 0x53) packet
to the modem. A companion `broadcast_demo.lua` script will call this every second with a fixed
26-byte vitals payload packed from live autopilot telemetry.

Protocol source: `/home/kofe/src/sine/link.contract/link.v1/api.h`
```c
struct viBroadcastMessage : public Header {
    uint32_t origin;
    uint8_t  payload[26];
} PACKED;   // sizeof=33, body_size=30
```

## File 1: `.sine/sdk/modules/sine.lua` — add `broadcast_msg`

### New constant (top of file, near other TYPE_ constants)
```lua
local TYPE_VI_SEND_BROADCAST_MSG = 0x53
```

### New public method (add to `M` table before `return M`)
```lua
-- Send a viSendBroadcastMessage. origin is a uint32; payload is a Lua string ≤ 26 bytes.
function M.broadcast_msg(origin, payload)
    if not _initialized then return end
    local pl26 = payload:sub(1, 26)
    if #pl26 < 26 then pl26 = pl26 .. string.rep('\0', 26 - #pl26) end
    -- header byte2: body_size=30 → 0x1E (bits[0:5]=30, is_remote=0)
    local raw = string.char(TYPE_VI_SEND_BROADCAST_MSG, 0x1E, 0x00)
             .. string.pack('<I4', origin)
             .. pl26
    _send_req(raw)
end
```

`_send_req` is the existing private helper that wraps raw bytes in the Sine envelope and sends the
MAVFTP message — no changes needed there.

## File 2: `.sine/sdk/broadcast_demo.lua` — new script

### 26-byte payload layout (all little-endian)
| Offset | Size | Type   | Field      | Source                              |
|--------|------|--------|------------|-------------------------------------|
| 0–3    | 4    | float  | bat_v      | `battery:voltage(0)`                |
| 4      | 1    | uint8  | bat_pct    | `battery:capacity_remaining_pct(0)` |
| 5–6    | 2    | int16  | alt_m      | `ahrs:get_position():alt() * 0.01`  |
| 7–10   | 4    | float  | gspd       | `gps:ground_speed(0)`               |
| 11     | 1    | uint8  | mode       | `vehicle:get_mode()`                |
| 12     | 1    | uint8  | gps_sats   | `gps:num_sats(0)`                   |
| 13     | 1    | uint8  | gps_fix    | `gps:status(0)` (0=none…6=RTK)      |
| 14–25  | 12   | —      | reserved   | zeros                               |

`string.pack('<fBhfBBB', bat_v, bat_pct, alt_m, gspd, mode, sats, fix)` → 14 bytes, then 12 zero bytes.

### origin value
`1` — fixed sentinel meaning "autopilot" (avoids needing a dynamic system ID lookup).

### Script skeleton
```lua
local sine = require("sine")

local ORIGIN        = 1
local BROADCAST_MS  = 1000

sine.init()

local last_tx = -BROADCAST_MS

local function make_payload()
    local bat_v   = battery:voltage(0) or 0.0
    local bat_pct = battery:capacity_remaining_pct(0) or 0
    local pos     = ahrs:get_position()
    local alt_m   = pos and math.floor(pos:alt() * 0.01 + 0.5) or 0
    local gspd    = gps:ground_speed(0) or 0.0
    local mode    = vehicle:get_mode() or 0
    local sats    = gps:num_sats(0) or 0
    local fix     = gps:status(0) or 0
    return string.pack('<fBhfBBB', bat_v, bat_pct, alt_m, gspd, mode, sats, fix)
        .. string.rep('\0', 12)
end

local function update()
    sine.update()
    local now = millis():tofloat()
    if now - last_tx >= BROADCAST_MS then
        last_tx = now
        sine.broadcast_msg(ORIGIN, make_payload())
        gcs:send_text(6, string.format(
            "BCast: bat=%.1fV/%d%% alt=%dm spd=%.1fm/s mode=%d sats=%d fix=%d",
            battery:voltage(0) or 0, battery:capacity_remaining_pct(0) or 0,
            math.floor((ahrs:get_position() and ahrs:get_position():alt() * 0.01 or 0) + 0.5),
            gps:ground_speed(0) or 0, vehicle:get_mode() or 0,
            gps:num_sats(0) or 0, gps:status(0) or 0))
    end
    return update, 100
end

return update, 100
```
